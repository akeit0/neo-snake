# 遊び方と設定

[READMEへ戻る](../README.md)

## 操作と画面

| 操作・表示 | 内容 |
| --- | --- |
| WASD / 矢印キー | 移動方向を変更。真後ろへの反転はできません。 |
| スワイプ / マウスドラッグ | 盤面、ウェーブ進捗、下部の操作エリアで方向を変更。指を離さず続けて曲がれます。進捗と下部は連続した操作エリアです。 |
| Enter / Space | 待機画面・ラン終了画面から開始。 |
| P / Ⅱ | 一時停止・再開。タブが非表示になったときも一時停止します。 |
| ビルド | 今のランで獲得した強化、ライフ、最高得点、チップを確認。 |
| 強化 | チップで永久強化を購入。次のランから有効。 |
| 設定 | 表示変更、永久強化のリセット／復元。開発版では数値調整・JSON入出力・テストランも追加。 |
| ? | ゲーム内の遊び方を表示。 |
| 音 | BGMと効果音の ON / OFF。初期状態は OFF。 |
| FX | パーティクル、リング、通知などの演出を切り替え。動きを減らす OS 設定では初期状態が OFF。 |

上部に SCORE（得点）、CHAIN（上段に連鎖倍率、下段に残り時間）、WAVE（現在のウェーブ）、LENGTH（体の長さ）を表示します。SCOREの下のBESTに保存済みの最高得点を常時表示します。盤面の左上のハートが残りライフです。爆弾を解放すると右上に再投擲までの秒数も表示します。下部の進捗には回収数、目標数、残り個数とバーを表示します。

## ゲームのルール

- 開始時は長さ4、ライフ2。盤面の端を通ると反対側へワープします。
- ピンクのエサは基本10点、金色のエサは基本30点。頭がエサのマスへ移動して食べると体が1つ伸びます。弾・マグネット・連鎖による回収も、1個につき体が1つ伸びます。得点・連鎖・ウェーブ進捗はどの回収方法でも全個分を加算します。成長率は回収方法によらず1固定です。
- エサを3.5秒未満の間隔で続けて回収すると連鎖。倍率は ×1 から増え、基本上限は ×20。得点に倍率がかかります。猶予と上限は強化で増やせます。
- 長さ7以上で、進行方向へ体を1つ消費して射撃します。発射間隔は基本0.8秒。射撃後の長さは6以上です。
- 弾はエサを回収できます。紫の障害物を撃つと25点を獲得してエサに変換。青い動く敵を倒すと50点を獲得して金色のエサに変換します。
- 障害物、青い敵、自分の体との衝突でライフを1失い、連鎖が途切れます。被ダメージ後は1.8秒間無敵。体の長さは変わりません。ライフ0でラン終了です。
- ウェーブが進むほど敵と障害物が増え、スネークと敵の移動が少しずつ速くなります。敵・障害物はウェーブ開始時に配置され、そのウェーブ中の補充はありません。

詳しい[難易度の基準](balance.md)と[強化一覧](upgrades.md)も参照してください。

## ウェーブ・スコア・チップ

毎ウェーブの目標を達成すると、ラン内強化の最大3択から1つ選んで次へ進み、クリアしたウェーブ番号 × 100点を獲得します。ウェーブ7突破時には追加で2,000点を獲得し、ウェーブ8から表示が `WAVE / ∞` に変わります。強化やライフは引き継ぎ、無限ウェーブでも強化を選べます。候補は有効なものだけで、残り2つなら2択、1つなら1択。候補がない場合は「次のウェーブへ」で続行します。

ライフ0でラン終了。最終スコアを中央に強調表示し、その下に最高記録を表示します。未購入の永久強化がある場合だけ、購入可能な種類数（または次の購入までの不足チップ）と購入画面へのボタンを表示します。最終得点 ÷ 100 の切り捨て + 到達ウェーブ × 2 のチップを獲得します。チップは永久強化に使えます。

最高得点を厳密に超えたランだけ「ハイスコア更新！」を表示します。同点は更新扱いにしません。FX OFFやOSの「視差効果を減らす」設定でも更新の文字は残ります。

## 言語 / Language

ヘッダーの「EN / 日本語」で表示言語を切り替えられます。強化・ヘルプ・設定・終了画面と読み上げ用ラベルも対応し、選択はこのブラウザに保存されます。切り替えても進行中のランや設定の入力値は保持されます。初期表示は日本語です。

Use “EN / 日本語” in the header to switch between English and Japanese. The choice is saved in this browser. Switching preserves the current run and unsaved settings form values.

## 音・BGM

BGMは8小節のオリジナルなチップチューンをWeb Audioで合成します。外部の音源ファイルや配信サービスは使いません。「音 ON」でプレイ中と強化選択中に再生し、一時停止・ダイアログ・ラン終了・バックグラウンド移行で止まります。再開時は曲の続きから再生します。音はブラウザの自動再生制限に合わせ、ボタン操作後に有効になります。

設定の「音量」でBGMとSFXをそれぞれ0〜100%に調整できます。初期値はBGM 70%、SFX 100%。0%はその音だけを消し、「音 OFF」は両方を停止します。音量は即時反映され、ブラウザに保存されます。永久強化のリセットでは音量は変わりません。

「BGMを移動テンポに同期」は初期ONです。設定可能なのは同期のON/OFFだけです。ONでは移動2回で1拍となり、テンポは `60 ÷ (1マスの移動間隔 × 2)` BPM。通常Wave 1の0.22秒では約136.4 BPM、0.1秒では300 BPMです。OFFでは128 BPM固定。Waveや設定でテンポが変わっても、音の高さは変わりません。移動の瞬間に拍を合わせ直す処理は行わず、曲の進行を保ったままテンポだけを変えます。設定はブラウザに保存します。

## 永久強化のリセット・復元

「永久強化をリセット」で購入済みレベルのみ0に戻します。チップと最高得点は維持し、購入費用は返金しません。現在のランは開始時の能力を保ち、次のランからリセットを適用します。「直前のリセットを戻す」で以前のレベルを復元できます。このバックアップもブラウザに保存されます。

## 保存される内容

最高得点、チップ、永久強化、ラップ・エコーの表示設定、BGM・SFXの音量、BGMのテンポ同期設定は、ブラウザの `localStorage`（キー: `snake-overdrive-v1`）に保存します。ブラウザやアクセス先ごとに記録は別で、サイトデータを削除すると記録も消えます。進行中のランは保存しません。開発版だけで使う数値設定は `snake-overdrive-balance-v1`、永久強化のリセット前レベルは `snake-overdrive-upgrade-backup-v1` に保存します。

表示言語は `snake-overdrive-language-v1` に保存します。

保存キーは改名前の `snake-overdrive-*` を継続して使用し、ネオスネークへの改名後も同じアクセス先なら記録・設定を引き継ぎます。
