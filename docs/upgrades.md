# ラン内強化と永久強化

[READMEへ戻る](../README.md)

## ラン内強化

このランだけ有効です。選択画面に「現在Lv → 次Lv / 上限」、ビルドに現在Lvと上限を表示します。`∞` はレベル上限なしです。同じ強化を選ぶとレベルが増えます。上限到達・効果が出ない強化は候補から除外します。以下の Lv は、その強化の獲得回数です。

| 強化 | 効果 |
| --- | --- |
| フード・フィーバー | 上限Lv.3。盤面のエサ数が基本7個から、1 Lv ごとに3個増加。 |
| チェイン・リアクター | 上限Lv.3。回収したエサの近くも連鎖回収。範囲は縦横の距離の合計で `1 + Lv` マス。連鎖回収したエサからも、さらに2段階まで回収が広がります。 |
| トリプル・ショット | 進行方向と左右の3方向へ同時発射。体の消費は1つ。上限Lv.1。獲得後は候補に出ません。 |
| ハングリー・マグネット | 上限Lv.2。頭の周囲のエサを回収。範囲は縦横の距離の合計で Lv マス。 |
| ゴールデン・バイト | 通常出現するエサが金色になる確率が基本12%から、1 Lv ごとに12ポイント増加。エサの獲得得点は基本値に対して1 Lv ごとに40%加算。 |
| セーフティ・スキン | 上限Lv.3。選ぶたびに現在のライフ +1。 |
| ロング・コンボ | 1 Lv ごとに倍率上限 +5。連鎖の時間猶予は増えません。 |
| ピアシング・ファング | 上限Lv.5。弾が Lv 回まで障害物・敵を貫通。1 Lv ごとに発射間隔を0.1秒短縮し、最短0.3秒。貫通付きの弾はエサも通過して回収できます。 |
| ブラスト・コア | 爆弾の爆風範囲を1 Lv ごとに +1マス。上限Lv.2。爆風範囲の上限に先に達する場合は、その時点で候補から除外。永久強化と合算して最大6マス。爆弾を解放したランでのみ出現。 |
| クイック・チャージ | 上限Lv.4。爆弾の基本投擲間隔を1 Lv ごとに15%短縮。最大60%短縮。爆弾を解放したランでのみ出現。 |
| コンパクト・ボディ | 選択時に現在の長さの30%を短縮（端数切り上げ）。最低4つ短縮し、長さ4は維持。長さ4以下、またはテール・カッターが有効なランでは候補に出ません。レベル上限なし。最低短縮数・短縮割合は数値設定で変更できます。 |

スコアに直接加算しない継続効果は、少ない取得回数で完成する上限にしています。上限は `assets/js/game-data.js` の `UPGRADE_LIMITS` に集約。得点加算のゴールデン・バイト、得点倍率のロング・コンボ、繰り返し短縮するコンパクト・ボディにはレベル上限を設けません。

候補の抽選は均等で、重み付けはありません。上限に達した強化が候補から抜けるため、コンパクト・ボディが相対的に出やすくなります。有効な候補が N 種類なら、コンパクトが3択に含まれる確率は `min(1, 3 / N)`（長さ5以上でテール・カッターが無効なランの場合）。例えば9種類なら約33%、6種類なら50%、3種類以下なら必ず表示されます。

ピアシング・ファングは射撃間隔が最短に達してもLv.5までは貫通回数が増えるため候補に残ります。ゴールデン・バイトは金色の確率が100%に達しても、得点加算の効果があるため候補に残ります。

## 永久強化

ラン終了後も保存され、購入後の次のランから適用されます。購入画面にも現在Lv・次Lv・上限を表示し、MAXの強化も一覧に残し、購入ボタンを無効化してMAXと表示します。購入済みLvはビルド・設定で確認できます。

| 強化 | 1段階の効果 | 最大段階 | 各段階の価格 |
| --- | --- | ---: | --- |
| タフ・スキン | 開始ライフ +1 | 3 | 40 / 200 / 800 チップ |
| チェイン・メモリー | 連鎖の猶予 +0.5秒 | 4 | 100 / 200 / 400 / 600 チップ |
| ボム・ランチャー | Lv.1で爆弾を解放。Lv.2・3で範囲と投擲間隔を強化 | 3 | 300 / 600 / 900 チップ |
| ラップ・エコー | ワープ先にあるものの色を入口の端に表示 | 1 | 800 チップ |
| テール・カッター | 回収で充填し、自分の体に弾を当てて末尾を切断 | 1 | 1000 チップ |

時間猶予は基本値 + 永久強化チェイン・メモリーのLv × 0.5秒です。通常強化のロング・コンボは倍率上限だけを上げます。ラン途中で購入しても、現在のランの能力は変わりません。

永久強化の価格はレベルごとの手動テーブルです。上表の各価格をそのまま使い、倍率による自動計算はしません。開発版の数値設定で各Lvの価格を独立して変更できます。JSONキーはLv.1が `armorCost` / `comboCost` / `bombCost`、Lv.2以降は `armorCost2` / `comboCost3` などのレベル番号付きです。ラップ・エコーとテール・カッターは1段階なので、`echoCost` / `cutterCost` を使います。

### ラップ・エコー

ラップ・エコーは、反対側の端の1マスにエサ・敵・障害物・自分の体がある場合、その位置に対応する入口の端へ色が少し染み出します。通常エサはピンク、金エサは金色、敵は青、障害物は紫、体はライム色。上下・左右の両方に対応し、角は両方向に表示します。空いている位置には表示しません。次のランから有効で、「設定」の「ラップ・エコーを表示」をOFFにすると即時に非表示になります。この設定は保存され、FXのON/OFFとは独立しています。価格は開発版の数値設定の `echoCost` で調整できます。

### テール・カッター

テール・カッターは次のランから有効です。有効なランではコンパクト・ボディを強化候補から外し、切断を長さ管理の手段にします。ラン途中で購入しても、そのランの候補には影響しません。エサを12個回収すると1回分が充填されます。頭・弾・マグネット・連鎖の回収がすべて対象。ストックは1回で、充填済みの回収は貯金されません。時間・旋回だけでは充填されません。画面左上の `CUT n/12` / `CUT READY` で状態を確認できます。

長さが20を超え、充填済みになると、切断できる末尾を薄い緑色で表示します。切断可能な個数は `min(floor(現在の長さ × 25%), 現在の長さ − 12)` で、端数は切り捨てます。この範囲に自動射撃の弾を当てると、着弾した部位を含めて末尾までをその位置から切断します。範囲外の部位では発動しません。長さ21なら末尾5つ、40なら末尾10つが対象です。切断はライフ・得点・連鎖・進捗を増減させず、エサも生成しません。充填は消費し、弾は貫通強化があっても消えます。複数の弾が当たっても1回分で連発できません。条件を満たさない場合は、自分の体を弾が通過し、充填も消費しません。充填はウェーブをまたいで保持し、新しいランで0に戻ります。長さが基準以下の場合、盤面のカッター状態表示も非表示になります。

開発版の設定の「テール・カッター」で充填個数 `cutterFoods`（12）、基準長さ `cutterThreshold`（20、超えると発動可能）、切断割合 `cutterRatio`（25%）、最低長さ `cutterMin`（12）を変更できます。価格は得点・永久強化価格の `cutterCost`（1000）。設定はJSON入出力に対応し、能力は次のランから適用します。旧JSONではこの5項目を標準値で補完します。

### 爆弾の動作

- ボム・ランチャーを購入した次のランから使用可能。体やチップを消費しません。
- 頭から縦横の距離の合計で6マス以内にある敵・障害物のうち、最も近いものへ投げます。対象がない間は待機します。
- 約0.55秒の弧を描く飛行後、狙ったマスで爆発します。動く敵への追尾はしません。
- 爆風範囲内の敵は50点と金のエサ、障害物は25点とエサに変換。エサを直接回収せず、スネークへの自爆ダメージもありません。
- 対象探索と爆風範囲は縦横の距離の合計で判定し、盤面の端を越えては届きません。
- ラン開始時の最初の投擲まで2秒。以降は下表の間隔。飛行と再投擲までの時間は一時停止・強化選択中に進みません。ウェーブ移行時に飛行中の爆弾は消えます。
- 爆弾は太い輪郭と着弾マーカーで表示。爆発の形・配色は[デザイン方針](design.md#fxの方針と現在の試作)を参照してください。
- FX を OFF にしても爆弾本体・着弾地点・残り秒数を表示します。

| 永久 Lv | 基本爆風範囲 | 基本投擲間隔 |
| --- | ---: | ---: |
| 1 | 2マス | 8秒 |
| 2 | 3マス | 7秒 |
| 3 | 4マス | 6秒 |

ブラスト・コアを足した爆風範囲は最大6マス。クイック・チャージの間隔は `基本投擲間隔 × (1 − min(0.60, Lv × 0.15))` で、永久 Lv.3・チャージ Lv.4以上なら2.4秒です。

永久強化の[リセット・復元](gameplay.md#永久強化のリセット復元)と、[開発版の数値調整](development.md#設定バランス調整開発版)も参照してください。
