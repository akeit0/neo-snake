# デザイン方針と参考資料

[READMEへ戻る](../README.md)

## UIのテーマ

NEO//SNAKEのUIは、**ネオブルータリズム（Neubrutalism / Neo-brutalism）を参考に制作した**ものです。太い濃色の輪郭、単色の色面、ずらした硬い影、大きく太い文字を組み合わせ、紙のカードやステッカーを重ねたような見た目を目指します。ゲーム内の演出には、同じ造形に合うコミック調の星・破片・放射線を使います。

これは本プロジェクトのデザイン意図です。下記の資料は、今回の方針の整理とFX試作で参照した資料であり、初期UIの特定のテンプレートや出典を示すものではありません。

## 色の役割

色を増やす場合も、主役の色と役割を維持します。CSSの基本色は `assets/css/style.css` の `:root`、盤面の色は `assets/js/game-render.js` を参照してください。

| 役割 | 基準色 | 用途 |
| --- | --- | --- |
| 紙・背景 | `#f3f1e8` | UIの地色 |
| インク | `#20201f` | 文字・輪郭・硬い影 |
| ライム | `#d8fa65` | スネークの胴・主要アクション |
| 紫 | `#bba1fa` | 障害物・強化カード |
| ピンク | `#ff8bae` | 通常エサ・ステッカー・アクセント |
| 青 | `#65c9ff` | 敵。エサと区別する |
| 金 | `#ffcc61` | 金エサ |
| 黄・オレンジ | `#ffd166` / `#ffae42` | 爆弾の演出 |
| クリーム | `#fff2cf` | 小さなハイライト・火花 |

スネークの頭・切断可能な尾・ダメージなどには、識別用の派生色も使います。FXの差し色は小さな火花や放射線に限定し、対象全体の色を別の役割の色へ変えません。通常エサの回収でライムや紫の破片を飛ばさないことも、この区別の一部です。

## UIを変更するときの基準

- 輪郭は基本2〜3pxの濃色。ボタン・カード・情報のまとまりを明確にする。
- UIの奥行きは、主にぼかさないオフセットの影で表す。影を実体の上に重ねない。
- 面は単色を基本とし、色や透明度のグラデーション、広い発光、ぼかしを装飾の主役にしない。
- 見出しは大きさと太さで強調する。説明・レベル・数値の読みやすさを維持する。英字はSpace Grotesk、日本語はNoto Sans JPを使う。
- スタンプの傾きやコミック的な形は局所的に使う。言語切り替え・強化選択で周囲のUIを急に動かさない。
- 盤面上の強化オーバーレイやラップ・エコーなど、機能上必要な透過表現は残す。画面全体を濃い色で覆う新しい演出は追加しない。

スマホのヘッダーは、ビルド＝積層アイコン、永久強化＝＋、設定＝歯車の固定幅ボタンで表示します。PCでは文字ラベルを表示します。言語を切り替えてもスマホのヘッダーは1行のままです。

ウェーブ後の強化選択は、元の盤面上の半透明表示を維持します。ヘッダー・スコア・進捗・スワイプ領域の位置や表示は変えません。盤面の実際の高さが低い場合は強化画面内の余白・見出し・アイコンを縮め、さらに低い場合は補助文とアイコンを省略します。選択肢の名前・説明・レベルは表示を維持します。

## FXの方針と現在の試作

派手さは粒子の量だけでなく、形・輪郭・短い動きの組み合わせで出します。短い立ち上がりと、広がった後の縮小を使い、透明化は最後の短い区間に抑えます。大きな半透明の塗り面で盤面を覆わない方針です。

| 場面 | 演出 |
| --- | --- |
| 通常移動・方向転換 | 移動前のマスに、自機はライムの四角、敵は青いひし形の軽い輪郭エフェクト。矢印は使わない。円・ギザギザ・四角い破片は出さない |
| エサの回収 | エサと同じ色の大きな四角い粒子が勢いよく飛び散る。輪は出さず、高CHAINでは粒子数を増やす |
| 敵・障害物の破壊 | 対象色の四角い破片、太い輪郭の輪と放射線 |
| 爆弾 | 赤い外側と橙の内側が接する太い菱形の帯。中央は空ける、黄色の内側の輪、ピンクとクリームの放射線・火花 |
| 飛んでいる弾 | くっきりした黄の外形、紫の軌跡、小さなピンク・黄のアクセント |
| CHAIN・OUCH・通知 | CHAINは四角いステッカーにピンク・青の放射線と小さな差し色の札を追加。高倍率は黄色と重ねた硬い影で強調。OUCHはピンクのギザギザ、BOOMは橙のギザギザに赤いアクセント。一般通知は紫。インク色の輪郭と硬い影、短い拡大を共通にし、発光やグラデーションは使わない |
| ダメージ | 赤系の破片・輪・短い衝撃。回収の演出と区別する |

四角い粒子は回収・破壊・体の短縮に使います。回収はエサと同じ色、破壊は対象色を主役にして区別します。移動の輪郭は1マス前の位置に小さく広がり、次の移動までに消します。細めの単色線だけで、破壊の粒子や太い帯と区別します。爆発の中心だけに短いクリーム色の星を置き、その後は輪・赤い外周と橙の菱形・放射線を残します。

描画順は `assets/js/game-render.js` の `draw()` を原本とします。盤面・端の表示・全体の影の後に輪を描き、障害物・エサ・敵を重ねます。破壊・回収の粒子はその前面に描いて手応えを出し、スネーク・弾・爆弾はさらに上に重ねます。大きな演出中も対象やスネークの位置が読めることを優先します。

粒子は最大650個、輪は最大45個に制限します。FX OFFでは粒子・輪を生成・描画せず、システムの「視差効果を減らす」相当の設定でも初期状態をOFFにします。今回の試作では操作テンポを変えるヒットストップや、新たな全画面フラッシュは追加していません。

## クリア・記録更新の演出

Waveクリアとラン終了では、左右から単色の四角い紙吹雪を飛ばすクラッカーを表示します。紙吹雪は盤面内のオーバーレイに収め、スコアの手前に描きます（操作は遮りません）。通常は72片、Wave 7突破は144片、ハイスコア更新は240片で、有限のアニメーションとして再生します。上向きの初速に空気抵抗を加え、上昇を滑らかに減速させます。落下速度は一定の低い終端速度に近づけ、左右の揺れ・傾き・紙の幅の変化でひらひら感を出します。発射の高さ・横方向の広がり・タイミング、落下速度、揺れの周期・位相・振幅・傾きを紙片ごとに変え、一斉に固まって動くのを避けます。1片の飛行は8〜12秒で、有限のアニメーションとして終了します。

ハイスコアは保存済みの最高得点を厳密に超えた場合だけ更新とし、「ハイスコア更新！」（英語はNEW HIGH SCORE!）をライム色の帯で強く表示します。スコアの青、RUN COMPLETEのピンク、リプレイのライムという役割と順序は維持します。FX OFFでも記録更新の文字は残し、紙吹雪とスコアの登場アニメーションは抑えます。

開発版での確認方法は[演出プレビュー](development.md#演出プレビュー)を参照してください。

## 参考資料

1. [Neubrutalism — The Definitive Guide to Neubrutalist Web Design](https://neubrutalism.com/)  
   太い輪郭、単色、硬いオフセットの影、文字の強弱という造形の整理に参照。すべてを同じ強さで強調せず、構造や読みやすさを保つ考え方を本UIの基準に採用しています。
2. [Lin et al. (2022), What Features Influence Impact Feel? A Study of Impact Feedback in Action Games](https://arxiv.org/abs/2208.06155) — [本文](https://arxiv.org/html/2208.06155v1)  
   着弾・着弾後・色の強調などのフィードバックの分類と、過剰な演出による読み取りへの影響を考えるために参照。対象は主にアクションゲームで、本ゲームに適した粒子数や配色を直接実証した資料ではありません。上記の具体的なFXは、テーマと盤面の視認性に合わせた本プロジェクトの試作判断です。

## ファビコンと紹介画像

ファビコンの原本は `assets/icons/favicon.svg`。紙色の背景に、中央のライム色のスネークの頭、黒い目、硬い影を配置します。小さい表示でも形が読めるよう、文字や装飾は入れません。PNGは同じSVGをブラウザで描画した画像から書き出しています。

- `assets/icons/favicon-32.png`：32pxのタブ用アイコン。
- `assets/icons/apple-touch-icon.png`：180pxのホーム画面用アイコン。
- `assets/icons/favicon-512.png`：512pxの画像素材。
- `assets/icons/favicon.ico`：16・32・48pxを収めた互換用アイコン。

紹介画像は `docs/images/title.jpg`（公開版の開始画面、900 × 1000px）と `docs/images/gameplay.png`（ユーザー提供の実際のプレイ画面）です。READMEにはWave 5・CHAIN ×20と破壊演出が見える実際のプレイ画像を使用します。盤面配置やスコアを編集せず、提供された画像をそのまま掲載します。
